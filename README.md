# POKÉSCAN AI Beta 2.5 – visueller Zwei-Karten-Pilot

Dieser Build testet erstmals **visuellen Kartenmotivvergleich** ohne Google Cloud und ohne Foto-Upload. Die Referenzen bestehen ausschließlich aus numerischen Bildmerkmalen der zwei vom Nutzer für Tests bereitgestellten Fotos. Originalfotos sind nicht im Paket enthalten.

**Unterstützte Testkarten:** Branawarz 084/128 (DE), Evoli 118/128 (DE). Andere Karten sind nicht unterstützt. Bei hoher Unsicherheit wird kein Treffer ausgegeben. Eine zuverlässige Identifikation von allen Pokémon-Karten oder 100 % Erkennungsquote ist nicht gegeben.

Das Suchergebnis wird mit TCGdex auf Namen und Nummer abgeglichen. Der Benutzer muss Set und Variante prüfen. Die bestehende Sammlung und Preisanalyse bleiben erhalten. Nicht automatisch hochgeladene Fotos verbleiben lokal; erkannte Suchbegriffe gehen an TCGdex.

Test: ZIP entpacken, sechs Dateien in GitHub Pages Root hochladen. iPhone mit beiden Originalfotos prüfen. Die Referenzfotos selbst sind nicht Bestandteil der veröffentlichten App.
